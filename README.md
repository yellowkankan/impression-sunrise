# 印象画室

一面展墙，六幅印象派名作。沿着墙走，走进画里，看懂印象派在看什么。

在线访问：https://yellowkankan.github.io/impression-sunrise/

| 展位 | 作品 | 主题 | 状态 |
|---|---|---|---|
| 01 | 莫奈《印象·日出》1872 | 光的一瞬 | 已开放（`sunrise/`） |
| 02 | 莫奈《干草堆》系列 1890–1891 | 时间 | 布展中 |
| 03 | 雷诺阿《煎饼磨坊的舞会》1876 | 彩色的阴影 | 布展中 |
| 04 | 德加《舞蹈课》1873–1876 | 抓拍的构图 | 布展中 |
| 05 | 莫里索《摇篮》1872 | 日常与亲情 | 布展中 |
| 06 | 修拉《大碗岛的星期天下午》1884–1886 | 色彩的科学 | 布展中 |

纯静态网页，无需构建。`index.html` 是展厅，每幅作品一个文件夹。
