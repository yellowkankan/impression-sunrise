# 印象画室

一面展墙，四幅莫奈。沿着墙走，走进画里，看懂印象派在看什么。

在线访问：https://yellowkankan.github.io/impression-sunrise/

| 展位 | 作品 | 主题 | 玩法 |
|---|---|---|---|
| 01 | 《印象·日出》1872 | 光的一瞬 | 拨开晨雾、在画里逛、20 秒画倒影、消失的太阳、1874 年的嘲讽 |
| 02 | 《撑阳伞的女人》1875 | 风与彩色的阴影 | 吹一阵风、在画里逛、点一点“白裙子”看它到底是什么颜色 |
| 03 | 《干草堆》系列 1890–1891 | 时间 | 拖动时间看九幅画渐变、只看颜色猜时间、九幅拼成一面墙 |
| 04 | 《睡莲》1906 | 水与倒影 | 把画倒过来、点水面分辨实物和倒影、用晚年的眼睛看 |

纯静态网页，无需构建，也不依赖任何外部服务（字体已内置在 `fonts/`）。部署方法见 [部署说明.md](部署说明.md)。

## 目录

```
index.html      展厅
sunrise/        01《印象·日出》（独立页面）
parasol/        02《撑阳伞的女人》
haystacks/      03《干草堆》
lilies/         04《睡莲》
engine/         02–04 共用的“画中漫游”引擎（笔触转场、雾、文字、点选、声音、加载）
gallery/        展厅缩略图
fonts/          内置字体（只含网站用到的字）
tools/          维护脚本
```

每幅作品文件夹里：`index.html` 页面骨架，`story.js` 故事和玩法，`data.js` 笔触方向等数据（由脚本生成）。

改动页面文字后，运行 `python3 tools/subset_fonts.py <完整字体文件夹>` 重新生成字体，否则新加的字会显示成备用字体。

## 图像

莫奈的作品均已进入公有领域。《印象·日出》《撑阳伞的女人》《干草堆》系列、梅索尼埃《1814 年法国战役》的图像来自维基共享资源等公开来源；《睡莲》图像来自印刷复制品，已去除印刷标记，颜色可能与原作略有出入。
“去掉太阳与倒影”“抹去倒影”的画面由程序修补，仅作示意；亮度、颜色占比等数据由程序在数字图像上测得，是近似值。
